# Gestión con Resultados — Tu Match Profesional

MVP funcional para analizar un aviso laboral frente a un CV.

## Ejecutar
```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Qué funciona
- Pegado de aviso laboral.
- Carga de CV PDF/DOCX/TXT.
- Extracción de texto.
- Diagnóstico inicial de coincidencias.
- Recomendaciones.
- Identidad visual de Gestión con Resultados.
